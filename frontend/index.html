How a case is decided

  1. Parse CSV / JSON / prompt → 11 features (missing values are never guessed)
  2. LightGBM + Isolation Forest → risk score 0–100 with per-feature contributions
  3. Laya (fine-tuned) → p(fraud) and gate: block / allow / human review
  4. Evidence rules → indicator list (the only source of indicators)
  5. Verdict flagged if Laya ≥ threshold or ML score ≥ 70
  6. Qwen 3.5 2B explains the verdict from that data, and its report is checked against the input before display
  7. You confirm or reject. The system only recommends.
